# Temp Converter

A tiny Python utility for converting between Fahrenheit and Celsius.

## Usage

```python
from temp_converter import fahrenheit_to_celsius, celsius_to_fahrenheit

fahrenheit_to_celsius(98.6)  # -> 37.0
celsius_to_fahrenheit(37)    # -> 98.6
```

## Functions

- `fahrenheit_to_celsius(fahrenheit)` - convert a Fahrenheit value to Celsius.
- `celsius_to_fahrenheit(celsius)` - convert a Celsius value to Fahrenheit.

Run the script directly to recieve a couple of example conversions printed to the console:

```bash
python temp_converter.py
```
